# Environment variables

cheap-mem is configured mostly by files, but a few dozen behaviours also
answer to an environment variable: a hook that is switched off for one session, a
search lane that is opt-in, a server that binds somewhere else. They were scattered
over the code until `src/envregister.mjs` gathered them into one register.

Two guards keep this page and the code from drifting apart (`test/envregister.test.mjs`):

- Every environment variable read in `src/`, `bin/`, `install/` or `hooks/` has a
  row in the register, and every row is still read somewhere. A new read without a
  row turns the test red; so does a row nobody reads any more. Standard variables
  of the operating system (`HOME`, `PATH`, `TMPDIR`, ...) are not registered.
- The table below is generated from the register. The test compares it with
  `renderTable()`; after a change, `node bin/mem envvars --markdown` prints the
  new block to paste between the two marker lines.

`mem envvars [--json]` prints the same register from the command line, with the
value each variable has in the current environment (secrets are shown as `set`
or `not set`, never as a value).

A variable that is not in the table is not a switch: there is none.

### Switches — they change what happens

| Variable | Default | Meaning |
| --- | --- | --- |
| `CHEAP_MEM_CALENDAR_ROUTE` | not set (no outside calendar) | Which route puts an appointment into a real calendar: SMTP invitation or the Google Calendar API. |
| `CHEAP_MEM_MAX_AUTHORITY` | not set (no ceiling; the digest sets `inferred`) | The highest authority a process may claim in what it writes. A model-backed writer must never produce a `user` entry; the digest and the reflector run under a lower ceiling. |
| `CHEAP_MEM_MCP_READONLY` | off (full tool profile) | With `1` the MCP bridge offers only the read tools. |
| `CHEAP_MEM_PROFILE` | off | With `1` the hooks write a profile of where their time went. |
| `CHEAP_MEM_SERVE_LOGIN` | on | With `off` the viewer's login is skipped (tests, local only). |
| `CHEAP_MEM_SERVE_OFFLINE` | off | With `1` the viewer loads nothing from outside. |
| `CHEAP_MEM_SERVE_READONLY` | off | With `1` the viewer shows everything and sets nothing. |
| `CHEAP_MEM_SERVE_SERVICE` | not set | Installer: whether to register the viewer as a service (`1`/`yes`). |
| `MEM_AFTER_FAILURE_OFF` | off | The after-failure hook (what the memory knows about a command that just failed) is switched off by `1` |
| `MEM_ANSWER_CHECK` | on | With `0` the stop-time answer check never blocks a turn. |
| `MEM_BEFORE_EDIT_OFF` | off | The before-edit hook (what the memory knows about a file about to change) is switched off by `1` |
| `MEM_BROADCAST_OFF` | off (a new error entry is broadcast) | With `1` `mem log error` does not broadcast the new error to the other sessions. |
| `MEM_CAPTURE_OFF` | off | The raw capture of a session transcript is switched off by `1` |
| `MEM_CATCH_FAIL_OFF` | off | The swallowed-failure hook is switched off by `1` |
| `MEM_CLOSING_REPORT` | on | With `0` the closing report of open duties is not shown. |
| `MEM_CORRECTION_WARN_OFF` | off | With `1` `mem correction` does not warn when a rare word of the old entry is missing from the correction. |
| `MEM_EXPAND` | off | With `1` the search also reads the `asked_as` phrasings stored next to an entry (document expansion, weight 0.3). Off, the search is bit-identical to before. |
| `MEM_GOLD_DAILY` | yes | With `no` the digest does not run the daily gold-miss collection. |
| `MEM_HEADLESS` | not set | Marks an unattended run (the digest, the reflector, any `claude -p` worker); its value names the run. Such a run is not captured, writes with a lowered authority, and may not confirm projects, categories, appointments or mail permits. |
| `MEM_HOOK_OFF` | off (all hook stages active) | Emergency stop for the whole hook chain in one session: every hook stage is switched off by `1`. A session without hooks has no memory. |
| `MEM_RAW_EXCLUDE` | off | With `1` the raw capture skips the session (the environment form of the exclude mark). |
| `MEM_RECALL_SERVER` | on (the hook asks the warm server when its socket exists) | With `0` the recall hook never asks the warm recall server and always searches directly. |
| `MEM_REFLECT` | off (opt-in) | With `1` the stop hook starts the model-backed reflector. |
| `MEM_RETRIEVE_NO_PULL` | off (the hook pulls when the clone is older than `MEM_RETRIEVE_FRESH_MIN`) | With `1` the recall hook never runs `git pull` first. |
| `MEM_RETRIEVE_OFF` | off | The recall hook (the relevant entries shown on a question) is switched off by `1` |
| `MEM_REWRITES` | on (the table ships empty) | `off` switches the whole query-rewrite table off. |
| `MEM_SEARCH_LEVERS` | the levers' own defaults | `off`, `all` or a list such as `h1,h3`: which Block H search levers are on (`mem search-levers`). |
| `MEM_SKIP_DIGEST` | off | Windows installer: with `1` the digest task is not registered. |
| `MEM_STOP_NO_PUSH` | off (the stop hook commits and pushes) | With `1` the stop hook does not push. |
| `MEM_SUBAGENT_START_OFF` | off | The sub-agent start hook is switched off by `1` |
| `MEM_WATCH_APPOINTMENTS` | on (when an appointments file exists) | With `off` the watcher's clock does not tick the appointments. |
| `MEM_WATCH_APPOINTMENTS_SYNC` | off | With `1` the appointment tick also syncs to the outside calendar. |

### Tuning — how much, how long, how often

| Variable | Default | Meaning |
| --- | --- | --- |
| `CHEAP_MEM_CALENDAR_REMIND_MIN` | not set (config, else 15) | Minutes before the appointment the outside calendar alarms. |
| `CHEAP_MEM_PARITY_DEBT_WARN_DAYS` | 14 | Days a parity debt may stand before `mem doctor` warns. |
| `CHEAP_MEM_SERVE_FULL_BUILD_MB` | measured in `src/dashboard-head.mjs` | Store size in MB above which the viewer builds only the light head. |
| `CHEAP_MEM_SERVE_HEAD_ENTRIES` | 120 | How many of the newest entries the viewer's first answer carries. |
| `CHEAP_MEM_SERVE_WINDOW_ENTRIES` | 30000 | How many of the newest entries the compact build lists. |
| `MEM_AFTER_FAILURE_MIN` | 2.0 | Score a hit needs before the after-failure hook shows it. |
| `MEM_AFTER_FAILURE_TOP` | 3 | How many hits the after-failure hook shows at most. |
| `MEM_ALARM_SECONDS` | 8 | Session-start hook: seconds `mem doctor --alarm` may take. |
| `MEM_BEFORE_EDIT_TOP` | 3 | How many hits the before-edit hook shows at most. |
| `MEM_BEFORE_EDIT_TRACE` | off | With `1` the before-edit hook says on stderr where it exited. |
| `MEM_CAPTURE_MIN` | 4096 | Smallest transcript, in bytes, the capture hook keeps (Windows hook). |
| `MEM_CATCH_FAIL_MIN` | 2.0 | Score a hit needs before the swallowed-failure hook shows it. |
| `MEM_CATCH_FAIL_TOP` | 3 | How many hits the swallowed-failure hook shows at most. |

| `MEM_DIGEST_ARGS` | `-p` | Windows digest: arguments of the model command. |

| `MEM_GOLD_TIMEOUT` | 300 | Seconds the digest gives the daily gold-miss collection. |
| `MEM_HANDLER_PROMPT` | the built-in prompt | The prompt the letter handler gives the model. |
| `MEM_RECALL_SERVER_RESTART_MS` | 60000 | Shortest gap between two automatic restarts of the recall server after a code change. |
| `MEM_RECALL_SERVER_WAIT_MS` | 2500 | How long the recall client waits for the server before searching directly. |
| `MEM_REFLECT_PROMPT` | the built-in prompt | The prompt the reflector gives the model. |
| `MEM_REFLECT_THRESHOLD_BYTES` | 400000 | Transcript growth, in bytes, before the reflector runs again. |
| `MEM_REFLECT_TIMEOUT` | 90 | Seconds one reflector run may take. |
| `MEM_RETRIEVE_BRANCH` | main | Branch the recall hook pulls. |
| `MEM_RETRIEVE_FRESH_MIN` | 10 | Minutes the clone counts as fresh before the recall hook pulls. |
| `MEM_RETRIEVE_MIN` | 5.0 | Score a hit needs before the recall hook shows it. |
| `MEM_RETRIEVE_REMOTE` | origin | Remote the recall hook pulls from. |
| `MEM_RETRIEVE_TIME` | 5 seconds | Time budget of one recall search, server and direct fallback alike. |
| `MEM_RETRIEVE_TOP` | 3 | How many hits the recall hook shows at most. |
| `MEM_SKILLUSAGE_DAYS` | 30 | Days of capture coverage `mem skills usage` needs before it gives a verdict. |
| `MEM_SKILLUSAGE_TIME_MS` | 8000 | Time cap, in milliseconds, for reading the captures. |
| `MEM_TODAY_SECONDS` | 5 | Session-start hook: seconds `mem today --line` may take. |
| `MEM_WATCH_BROKEN_WAIT` | 60 | Seconds the watcher waits after a failed poll. |
| `MEM_WATCH_HANDLER_TIMEOUT` | 300 | Seconds the letter handler may take. |
| `MEM_WATCH_INTERVAL` | 15 | Seconds between two polls of the inbox watcher. |
| `MEM_WATCH_STALE_MIN` | 120 | Minutes after which the watcher's lock counts as stale. |

### Places — where something lives

| Variable | Default | Meaning |
| --- | --- | --- |
| `CHEAP_MEM_ARCHIVE` | not set (`raw/YYYY/MM/` inside the root, or the place `mem archive` recorded) | Where the raw archive is kept; a mount outside the repository. |
| `CHEAP_MEM_CHECK_FILE` | `<root>/checked.jsonl` | Where `mem check-record` writes its rows. |
| `CHEAP_MEM_CODE` | not set (the hook uses the root as the code directory) | Where the cheap-mem code lives when it is not the memory root itself (the sub-agent and session-start hooks). |
| `CHEAP_MEM_GOLD_FILE` | `~/.cheap-mem-gold/...` outside the repository | The gold-question log; kept outside the repository on purpose. |
| `CHEAP_MEM_MISS_GOLD` | `<root>/.mem/local/miss-gold.jsonl` | The local, never-committed file of real retrieval misses. |
| `CHEAP_MEM_PKG` | set by the git hook installer | The package directory the installed git hooks call back into. |
| `CHEAP_MEM_RELEASE_BASE` | `<root>-release` | Base directory of the release copies. |
| `CHEAP_MEM_ROOT` | not set (the CLI walks up from the current directory to a `.mem/config.json`) | The memory root. The installer writes it into every hook; the CLI, the hooks and the servers read it. |
| `CHEAP_MEM_SERVE_LOGIN_DIR` | `.pipeline/` of the root (gitignored) | Where the viewer keeps its login state. |
| `CHEAP_MEM_STATE_SIGNAL_WORDS` | not set (the built-in word list) | A file of the words that mark a question as being about the current state. |
| `CHEAP_MEM_USER_PATTERNS` | not set (the built-in patterns) | A JSON file of the user-habit patterns for `mem user`. |
| `CHEAP_MEM_VERIFY_FILE` | `~/.cheap-mem-verify/...` outside the repository | The verification log. |
| `CLAUDE_CONFIG_DIR` | not set | Claude Code's own configuration directory; its `skills/` is added to the skill catalogue and the MCP setup looks there. |
| `CLAUDE_HOME` | `~/.claude` | Where the Claude Code user configuration lives (`mem doctor`, the installer). |
| `CLAUDE_TRANSCRIPT_PATH` | not set (the hook input names the transcript) | The session transcript the capture hook reads, when the hook input does not name one. |
| `MEM_AFTER_FAILURE_TURNS` | `<root>/.mem/after-failure-turns` | Directory of the once-per-turn claims of the after-failure hook. |
| `MEM_ANSWER_CHECK_PATTERNS` | not set (`.mem/answer-check-patterns.json` or the built-ins) | A JSON file of the answer-check patterns. |
| `MEM_BEFORE_EDIT_MARKS` | `<root>/.mem/before-edit` | Directory of the per-session marks of the before-edit hook. |
| `MEM_CATCH_FAIL_TURNS` | `<root>/.mem/catch-fail-turns` | Directory of the once-per-turn claims of the swallowed-failure hook. |
| `MEM_COMMAND_GUARD_MARKS` | `<root>/.mem/command-guard-marks` | Directory of the per-session marks of the command guard. |
| `MEM_DIGEST_CMD` | `claude -p` | The model command the digest starts (Windows: `claude`, arguments from `MEM_DIGEST_ARGS`). |
| `MEM_DIGEST_LOG` | `<root>/.mem/digest.log` | Log file of `bin/mem-digest`. |
| `MEM_HANDLER_CMD` | `claude -p` | The model command that handles an incoming letter. |
| `MEM_RECALL_SERVER_CODE_STATE` | the server's own code directory | Tests only: which directory's `src/` the server watches to restart itself after a code change. |
| `MEM_RECALL_SERVER_DIR` | `.pipeline/` of the root | Where the warm recall server keeps its socket and key; set it when the root path is too long for a Unix socket. |
| `MEM_REFLECT_CMD` | `claude -p` | The model command of the reflector. |
| `MEM_RETRIEVE_ROOTS` | `~/cheap-mem /work/cheap-mem /home/user/cheap-mem` | Space-separated roots the recall and after-failure hooks probe when `CHEAP_MEM_ROOT` is not set. |
| `MEM_RETRIEVE_TURNS` | `<root>/.mem/retrieve-turns` | Directory of the once-per-turn claims of the recall hook. |
| `MEM_STOP_ROOTS` | `~/cheap-mem /work/cheap-mem /home/user/cheap-mem` | The same probe list for the stop hook. |
| `MEM_WATCH_HANDLER` | `bin/mem-handle-post` next to the watcher | The program the watcher starts for a new letter. |
| `MEM_WATCH_LOG` | `<root>/.mem/watch.log` | Log file of `bin/mem-watch`. |
| `MEM_WORKFLOW_MARKS` | `<root>/.mem/workflow-marks` | Directory of the per-session marks of the workflow hint. |

| `CHEAP_MEM_CHECK_HOUSE` | `package.json` name, else the directory name | The house a check-record row names. |

| `CHEAP_MEM_SMTP_FROM` | not set | Sender of the invitation. |
| `CHEAP_MEM_SMTP_TO` | not set | Recipient of the invitation. |
| `CHEAP_MEM_SMTP_USER` | not set | SMTP login name. |
| `CHEAP_MEM_TZ` | `config.timezone`, else the system zone | Time zone for appointments (input and output; UTC is stored). |
| `CLAUDE_CODE_REMOTE` | set by Claude Code in its cloud | Marks the cloud surface; read, never set. |
| `CLAUDE_CODE_SESSION_ID` | set by Claude Code | The session `mem raw-capture` captures when `--session` is not given. |

| `MEM_WATCH_WHO` | required by the watcher and the letter handler | Who this installation is in the inbox (a participant name from `.mem/config.json`). |

### Internal — handed from one cheap-mem process to the next

Set by a hook script for the program it starts, or plain shell variables that only look like environment
variables. Nothing to configure: `CM_REBUILD_LOCK`, `MAX`, `MEM_AF_REASON`, `MEM_AF_SESSION`, `MEM_AF_START_MS`, `MEM_ALARM_RC`, `MEM_ALARM`, `MEM_BE_START_MS`, `MEM_BT_CMD`, `MEM_CAP`, `MEM_CLI`, `MEM_COUNT`, `MEM_DETOUR_REASON`, `MEM_ERRSIG`, `MEM_FP`, `MEM_HOOK_START_MS`, `MEM_J_BYTES`, `MEM_J_HITS`, `MEM_J_PATH_REASON`, `MEM_J_PATH`, `MEM_J_QB`, `MEM_J_REASON`, `MEM_J_ROOT`, `MEM_J_SESSION`, `MEM_J_SRC`, `MEM_J_START`, `MEM_LEVEL`, `MEM_MARK`, `MEM_PICK`, `MEM_Q`, `MEM_RECALL_SERVER_PARENT`, `MEM_RH_CWD`, `MEM_RH_MIN`, `MEM_RH_PATH_REASON`, `MEM_RH_PATH`, `MEM_RH_PROMPT`, `MEM_RH_QB`, `MEM_RH_SESSION`, `MEM_RH_START_MS`, `MEM_RH_TRANSCRIPT`, `MEM_RH_TURNS`, `MEM_RH_WORKFLOW`, `MEM_ROOT_ARG`, `MEM_SS_CODE`, `MEM_SS_INPUT`, `MEM_SS_IN`, `MEM_SS_SRC`, `MEM_SS_START_MS`, `MEM_START`, `MEM_TODAY`, `MEM_USER_HABITS`, `RESERVE`, `ROOT`, `TRANSCRIPT_PATH`.
